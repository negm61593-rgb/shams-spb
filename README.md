# مطعم شمس سانت بطرسبرغ • Shams Restaurant SPb
### قائمة طعام إلكترونية تفاعلية متعددة اللغات + لوحة إدارة سحابية متقدمة
**Аутентичная египетская кухня в Санкт-Петербурге • Комендантский пр., 61К**

---

## 🌟 نظرة عامة (Overview)
موقع وقائمة طعام إلكترونية (Digital Menu & Web App) لمطعم **«شمس • Shams»** للمأكولات المصرية والشاورما الحلال في سانت بطرسبرغ (تقييم 5.0 على خرائط ياندكس - 470+ تقييم).
تم تصميم النظام ليعمل عبر مسح كود QR موضوع على طاولات الطعام وبوسترات واجهة المحل، مع ثبات كامل للرابط والباركود حتى بعد إجراء أي تعديلات مستقبلية.

---

## 🚀 المميزات الرئيسية (Key Features)

1. **قائمة طعام تفاعلية فائقة السرعة (Interactive Digital Menu)**:
   - 65 وجبة بأعلى درجات الدقة مع الصور الواقعية والوزن بالجرام والأسعار.
   - دعم كامل لـ 3 لغات: **الروسية (الافتراضية)، العربية، والإنجليزية** مع عزل لغوي كامل وتبديل فوري.
   - تصفية سريعة حسب الأقسام (شاورما، فلافل، بوكسات، برجر، هوت دوج، مشروبات وصوصات).
   - سلة طلبات تفاعلية لإرسال الطلب مسبقاً عبر **واتساب أو تليجرام**.
   - دعم الوضع الليلي والنهاري (Dark / Light Mode) وتصميم متجاوب 100% مع كافة أحجام الهواتف.

2. **لوحة تحكم إدارية محصنة (Admin Panel)**:
   - مسار اللوحة: `/admin.html`
   - حماية بكلمة مرور مشفرة وقوية مع نظام Rate Limiting ذكي (5 محاولات خاطئة ثم حظر مؤقت لمدة 15 دقيقة مع عداد تنازلي حي).
   - إضافة، تعديل، حذف الأطباق، وتعديل الأسعار والكميات.
   - رفع صور الأطباق مع ضغط ومعالجة تلقائية.
   - ترجمة فورية تلقائية بين الروسية والعربية والإنجليزية.
   - زر التوفر السريع (In Stock / Out of Stock) لحجب الوجبات النافذة بضغطة زر.

3. **الباركود الثابت الدائم (Permanent QR Code)**:
   - الباركود المطبوع على الطاولات وخارج المحل يوجّه الزبون مباشرة إلى الرابط الثابت للمتجر.
   - أي تعديل في الأسعار أو الوجبات من لوحة الإدارة يظهر للزبائن فوراً على نفس الرابط دون أدنى حاجة لإعادة طباعة الباركود إطلاقاً!

## 🛠️ التشغيل والبيئة (Tech Stack)
- **Backend**: Pure Node.js (بدون تبعيات خارجية معقدة - أقصى سرعة وأمان).
- **Frontend**: HTML5, Modern Vanilla JS, Tailwind CSS, FontAwesome.
- **Port**: `process.env.PORT || 3000`

---

## 🔒 الأمان والمصادقة (Security)
- التوثيق عبر جلسات آمنة (Bearer Session Tokens).
- حماية ضد Path Traversal وهجمات الـ Brute Force.
- ترويسات أمان قياسية: `X-Content-Type-Options`, `X-Frame-Options`, `X-XSS-Protection`.
